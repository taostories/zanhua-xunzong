## 四章体验

1. 芳花撷取：点击四种花，弹窗简短介绍花材，居中按钮继续采花。可重复采摘，集齐四种后衔接剧情。
2. 螺髻盘梳：点击木梳，镜中出现浅色光标和发亮落点，向下轻梳或点击落点完成梳理；随后收拢头发、用发绳束稳、插入骨簪。镜中不显示文字标签。保留拖拽与点选操作，错序不清空进度。
3. 花围缀编：纯文字选择家常错落款或节庆浓艳款，四段花簇完成拼图后衔接故事。两款完整透明花围图已分别接入。
4. 日暮传韵：对话下移，上方为游客与主角图片预留位置。三轮提问、九条回应分支，无失败或分数，推进按钮统一为“继续”。问答后点击“别上素馨”，解锁完整图鉴与结尾。

移除了听提示、每章手记与重读入口。结尾保留重新体验，没有人物留位面板或不可用的保存按钮。
